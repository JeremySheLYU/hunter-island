# 獵人島 · Be a Survival

十月十日，Tom 從跳蚤市場帶回了一張模糊的藏寶圖。出航前，你和 Jerry 只能再選兩件裝備。海風、雨水和滿載的背包，都會改變你回家的路。

## 單人遊玩

解壓整個資料夾，用 Safari、Chrome、Edge 或 Firefox 開啟 `index.html`。也可直接用另外提供的單檔 `Hunter-Island.html` 離線遊玩。原始碼版的圖片、樣式與腳本需和入口放在同一個資料夾。

選 Tom 或 Jerry，挑兩件起始裝備，再按「整裝登島」。每人自備兩份乾糧和兩份飲水。碼頭上的 W 有第一條線索。可先留在海邊熟悉操作，靠近任何採集點後開啟「互動」，便能看到當下可做的事。

單人進度會自動儲存在目前使用的瀏覽器，返回主選單後選「繼續探險」。私密模式、清除瀏覽器資料或改用其他瀏覽器、檔案路徑、伺服器網址，都可能無法讀取原存檔。畫面失去焦點或打開面板時，單人世界會暫停。

## 合作遊玩

需要一部裝有 Node.js 18 或以上版本的電腦擔任主機。無需安裝任何 npm 套件。

1. Mac 可以在終端執行 `sh Launch.command`。也可從任何支援 Node.js 的系統，在本資料夾的終端執行 `node server.cjs`。
2. 在主機瀏覽器開啟終端顯示的本機網址，預設為 `http://localhost:4177`。選「多人同行 → 建立房間」。選角色和裝備，登島後記下六位房號。
3. 同一區域網路的朋友使用終端顯示的「同網路好友」網址，在瀏覽器選「多人同行」，輸入房號，再選剩餘角色。手機可直接用觸控操作。主機瀏覽器內也可測試單人模式。
4. 若 Mac 詢問網路連線權限，允許遊戲伺服器接受本地連線。使用會隔離裝置的訪客或校園 Wi-Fi 時，請改用允許裝置互連的網路。

至多四名玩家可在同一座島上活動。房主選 Tom 或 Jerry，隊友還可選 Cassia 或旺財。倒下的同伴可以接受援助，物品可傳遞或放在地上。房間內的時間持續前進，開背包時隊友仍可行動。重新整理同一個分頁可重新加入原房間。離開房間或結束伺服器程序會影響重連，房主主動退出會結束房間。

遠端玩家必須能連到同一部伺服器。可把整個資料夾放在可執行 Node.js 的主機並啟動 `node server.cjs`，服務可由 `HOST`、`PORT` 環境變數設定。房間存於伺服器記憶體，程序結束即失效。

## 島上生活

- **負重與行進**　不同角色的體力、速度和容量各異。奔跑和重裝會增加消耗，飲水、進食和休息可從背包或互動選單進行。
- **日夜與天氣**　風雨、濕衣與夜色會影響體溫及休息，夜間林地有野生動物。採集材料可以製作營火、棚架、工具和背囊。
- **測繪與觀察**　備一張素描地圖，或找材料自行製作。經過的地形會留在圖上，登高可以測繪得更遠。Lili 在營地等你交回自然觀察作業。
- **找尋寶藏**　看手札中的當前目標和角色的行動記錄。重要調查會消耗遊戲內時間和體力。遺跡有多種取寶方式，取得紀錄盒後需帶回碼頭。
- **一起出發**　Cassia 擅長攜帶裝備。旺財用氣味記路，看到人類手勢時要靠動作猜意思。隊員都有自己的背囊，也共享故事進度。

## 開發資訊

原始遊戲企劃與角色設定由 She LYU 撰寫，原案的背景研究署名 Zhizhen。本版本依據該企劃實作。標題插畫、角色肖像及本版程式由 AI 協作製作。遊戲內的時間、生理數值及物品功效為玩法設定。

- `app.js`、`game.css`、`index.html` 管理標題、備裝、存檔與輸入。
- `world.js` 產生島嶼、繪製像素場景與地圖。
- `sim.js` 管理時間、角色、任務、背包、製作及結局。
- `hud.js`、`hud.css` 管理遊戲介面、選單及手機觸控。
- `sound.js` 即時合成海浪、旋律和操作音效。
- `net.js`、`server.cjs` 管理房間和多人狀態同步。
